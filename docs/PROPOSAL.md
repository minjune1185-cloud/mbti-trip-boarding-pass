# AI 밈 여행지 추천 모바일 웹앱 기획서 (MVP)

## 한 문장
여행 조건(스타일·MBTI·예산·기간·치안 중요도·동행자) 객관식 선택 → AI가 한국인 인기 30개국 중 여행지·이유를 밈 텍스트 보딩패스 카드로 추천 → 이미지 저장해 카톡·인스타 직접 공유하는 모바일 전용 무료 웹앱 (1차 DB 없음, 2차 연구 데이터 DB 확장 가능 구조).

---

## 왜
* 해외여행 가고 싶음. 국가 정보 부족, 검색 피로 큼.
* 객관식 선택만으로 밈 텍스트 추천받고 이미지 저장·공유 니즈 해결.
* 추후 유저 성향·추천 매칭 데이터 쌓아 연구 데이터로 활용 목적.

---

## 누가·어디서
* **누가**: 해외여행 가고 싶지만 다른 나라 잘 모르는 사람.
* **어디서**: 모바일 웹 브라우저 전용 (무료 웹앱).

---

## 핵심 기능

### 1. 여행 조건 객관식 입력 (`input_payload` JSON 생성)
* **여행 스타일** (택1): 휴양·호캉스 / 맛집·먹방 / 관광·랜드마크 / 쇼핑·도시 / 액티비티·자연
* **본인 MBTI**: 16종 선택
* **예산 (1인)**: 50만 이하 / 50~100만 / 100~200만 / 200~300만 / 300만 이상
* **기간**: 2박 3일 이하 / 3박 4일 / 4박 5일 / 1주일 이상
* **치안 중요도** (택1): 치안 최우선 / 보통(무난) / 모험 가능
* **동행자**: 혼자 / 친구(텐션 높음) / 친구(힐링) / 연인 / 가족 *(‘혼자’ 선택 시 동행자 MBTI 항목 숨김)*
* **동행자 MBTI**: 16종 + 모름

### 2. AI 밈 텍스트 추천 카드 생성 (30개국 한정 + DB 확장 대비 구조)
* **추천 풀 (정적 상수 30개국)**:
  * 아시아(13): 일본, 베트남, 태국, 대만, 필리핀, 중국, 홍콩, 싱가포르, 인도네시아, 말레이시아, 몽골, 라오스, 캄보디아
  * 미주·대양주(5): 미국, 캐나다, 멕시코, 호주, 뉴질랜드
  * 유럽·중동(12): 프랑스, 이탈리아, 스위스, 영국, 스페인, 독일, 체코, 오스트리아, 포르투갈, 네덜란드, 크로아티아, 튀르키예
* **AI 모델/제어**: `gemini-3.5-flash-lite` (`@ai-sdk/google` / `GEMINI_API_KEY`) 사용. `Structured Outputs(JSON)` 강제 (`country`, `meme_title`, `meme_reason`, `tags`). 어뷰징 방지용 IP 기반 `Rate Limit` (분당 3회, 일 20회).
* **카드 UI**: 항공권 보딩패스(Boarding Pass) 컨셉 세로형 카드. 밈 텍스트만 배치.
* **2차 DB 확장 대비**: 1차 MVP는 `Stateless` (DB 미연동). 단, 백엔드 API 응답 직전 `saveResearchLog(input_payload, ai_result, timestamp)` 형태의 빈 인터페이스(Stub) 분리해 2차 때 DB(`PostgreSQL`/`Supabase` 등) 바로 연결 가능하게 설계.

### 3. 결과 카드 이미지 저장
* `html-to-image` (또는 `html2canvas`)로 보딩패스 카드 영역 캡처 후 고정 규격 없이 기기 이미지 다운로드.
* 유저가 갤러리에서 카톡·인스타 직접 업로드.

---

## 안 할 것
1. **1차 MVP DB 연동 및 영구 저장**: 1차에는 DB 안 붙임. 유저 기록·히스토리·연구 데이터 실제 저장은 2차 범위.
2. **PC 웹/반응형 최적화**: 모바일 웹 뷰포트 전용. PC 화면 레이아웃 대응 안 함.
3. **밈 이미지 생성·삽입**: 밈 텍스트만 사용. AI 이미지 생성·외부 밈 짤 첨부 없음.
4. **외부 공유 API 연동**: `Kakao SDK`, `Web Share API` 미적용. 단순 이미지 다운로드만.
5. **30개국 외 추천·예약·결제·로그인**: 지정 30개국 외 제외. 항공·숙소 예약, 일정표, 결제, 회원가입, 커뮤니티, 랭킹 없음.

---

## 완료 조건
- [ ] 모바일 브라우저 첫 화면에 7개 객관식 입력 항목(치안 중요도 포함) 보임.
- [ ] 동행자에서 '혼자' 선택 시 동행자 MBTI 선택지가 화면에서 사라짐.
- [ ] 모든 항목 선택 후 제출 버튼 누르면 30개국 중 1곳과 밈 텍스트가 담긴 보딩패스 결과 카드가 화면에 뜸.
- [ ] 개발자 도구/서버 로그에서 요청(`input_payload`)과 응답(`ai_result`)이 정해진 `JSON` 스키마로 분리 출력되고, 빈 `saveResearchLog()` 훅 호출 확인됨.
- [ ] 저장 버튼 누르면 결과 카드가 텍스트 깨짐·잘림 없이 이미지 파일로 다운로드되어 모바일 갤러리에서 정상 열림.
- [ ] 같은 IP로 제한 횟수 초과 요청 시 차단 메시지 화면에 뜸.

---

## 이게 되면 바뀌는 것
* 해외 잘 모르는 유저도 객관식 선택 몇 번으로 취향·예산·동행자에 맞는 여행지 후보 획득.
* 보딩패스 밈 이미지 카톡·인스타 직접 공유로 별도 광고 없이 바이럴 유입 발생.
* 1차 MVP 검증 끝난 뒤 코드 갈아엎지 않고 DB만 연결해 MBTI·예산·여행지 매칭 연구 데이터 즉시 수집 가능.
