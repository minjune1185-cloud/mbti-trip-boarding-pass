# 「성격따라 따라가는 여행」 화면설계서 (MVP)

> **서비스 개요**: 여행 조건 객관식 선택 → AI가 한국인 인기 30개국 중 여행지·이유를 밈 텍스트 보딩패스 카드로 추천 → 이미지 저장 후 직접 공유하는 모바일 전용 무료 웹앱 (1차 Stateless / 무료티어 AI API 기반 운영)

## 1. 화면 목록 (총 4개)

| ID | 화면명 | 대응 핵심 기능 | 
| ----- | ----- | ----- | 
| S1 | 여행 조건 입력 (첫 화면) | 기능 1: 여행 조건 객관식 입력 (`input_payload` JSON 생성) | 
| S2 | 보딩패스 결과 카드 | 기능 2: AI 밈 텍스트 추천 카드 생성 / 기능 3: 결과 카드 이미지 저장 | 
| S3 | 개인 요청 제한 차단 | 기능 2: IP 기반 `Rate Limit` (분당 3회, 일 20회) 어뷰징 방지 | 
| S4 | 서비스 일시 중단 (무료티어 소진) | 기능 2: 무료티어 API 쿼터 소진 시 서비스 중단 제어 | 

## 2. 화면 흐름

`S1 여행 조건 입력` → (제출 · 로딩 오버레이) → `S2 보딩패스 결과 카드` (이미지 저장 / 다시 추천받기 → `S1`) / IP 제한 초과 시 `S3 개인 요청 제한 차단` / 무료티어 소진 시 `S4 서비스 일시 중단`

## 3. 화면별 상세

### S1. 여행 조건 입력 (첫 화면)

* **대응 핵심 기능**: 여행 조건 객관식 입력 (`input_payload` JSON 생성)

* **보이는 것**:

  * **상단 헤더**: 서비스명 **「성격따라 따라가는 여행」** 및 한 줄 소개 *(예: "조건만 고르면 AI가 밈 보딩패스로 여행지 발권!")*

  * **7개 객관식 입력 항목** *(모바일 웹 뷰포트 전용)*:

    1. **여행 스타일 (택1)**: 휴양·호캉스 / 맛집·먹방 / 관광·랜드마크 / 쇼핑·도시 / 액티비티·자연

    2. **본인 MBTI**: 16종

    3. **예산 (1인)**: 50만 이하 / 50\~100만 / 100\~200만 / 200\~300만 / 300만 이상

    4. **기간**: 2박 3일 이하 / 3박 4일 / 4박 5일 / 1주일 이상

    5. **치안 중요도 (택1)**: 치안 최우선 / 보통(무난) / 모험 가능

    6. **동행자**: 혼자 / 친구(텐션 높음) / 친구(힐링) / 연인 / 가족

    7. **동행자 MBTI**: 16종 + 모름

  * **제출 버튼**: `내 여행지 보딩패스 발권하기`

  * **하단 무료티어 고지 문구**: *"본 서비스는 무료티어 AI로 운영되며, 일일 무료 할당량이 소진되면 충전 전까지 발권이 중단될 수 있습니다. 입력하신 정보는 별도 저장되지 않습니다."*

  * **로딩 오버레이 (제출 시)**: 화면 전체 반투명 오버레이 + 스피너 + 대기 문구 *(예: "성격따라 따라가는 여행 항공사에서 보딩패스 발권 중...")*

* **누를 수 있는 것 / 누르면 생기는 일**:

  * **각 객관식 선택지** → 해당 조건 선택 (`input_payload` 구성)

  * **동행자 중 '혼자'** → 동행자 MBTI 항목 화면에서 숨김 (필수 입력 조건에서도 자동 제외)

  * **동행자 중 '혼자' 외 항목** → 동행자 MBTI 항목 노출 (필수 입력 조건 포함)

  * **제출 버튼 (활성화 상태)** → 중복 클릭 방지 및 로딩 오버레이 노출 → AI 추천 요청

    * 성공 시 → `S2` 이동

    * IP 제한(분당 3회, 일 20회) 초과 시 → `S3` 이동

    * 무료티어 할당량 소진 시 → `S4` 이동

    * 일시적 네트워크/API 오류 시 → 로딩 해제 후 하단 토스트 메시지(*"일시적인 오류가 발생했어요. 잠시 후 다시 시도해 주세요."*) 노출

* **비어 있을 때**:

  * 초기 진입 시 7개 항목 모두 미선택 상태.

  * 필수 항목이 하나라도 비어 있으면 **제출 버튼 비활성화(Disabled)** 상태 유지 및 버튼 상단에 안내 문구(*"모든 조건을 선택하면 발권할 수 있어요"*) 표시.

### S2. 보딩패스 결과 카드

* **대응 핵심 기능**: AI 밈 텍스트 추천 카드 생성 + 결과 카드 이미지 저장

* **보이는 것**:

  * **항공권 보딩패스(Boarding Pass) 컨셉 세로형 카드** *(이미지 캡처 대상 영역, 밈 이미지 없음)*:

    * 상단 브랜딩: **「성격따라 따라가는 여행」** AIRLINES / BOARDING PASS

    * 추천 국가명 (`country` — 30개국 중 1곳)

    * 밈 타이틀 (`meme_title`) 및 밈 추천 이유 (`meme_reason`)

    * 해시태그 (`tags`)

    * 탑승 조건 요약: 유저가 선택한 본인 MBTI, 예산, 기간, 동행자, 치안 중요도 정보 *(공유 시 맥락 전달용)*

  * **이미지 저장 버튼**: `보딩패스 이미지 저장`

  * **인앱 브라우저 안내 문구**: *"카톡·인스타 앱 내에서 저장이 안 된다면, 외부 브라우저(크롬·사파리)로 열어 저장해 주세요."*

  * **재시도 버튼**: `다시 추천받기`

* **누를 수 있는 것 / 누르면 생기는 일**:

  * **보딩패스 이미지 저장 버튼** → `html-to-image` (또는 `html2canvas`)로 카드 영역 캡처 후 기기 이미지 다운로드 *(외부 공유 API 미사용)* → 완료 시 하단 토스트 메시지(*"보딩패스가 저장되었어요! 갤러리에서 카톡·인스타에 공유해 보세요."*) 노출

  * **다시 추천받기 버튼** → `S1` 이동 (기존 선택값 초기화)

* **비어 있을 때**:

  * 1차 `Stateless` (DB 미연동) 구조이므로, 결과 데이터 없이 URL 직접 접근하거나 새로고침한 경우 → `S1`으로 자동 리다이렉트(이동).

### S3. 개인 요청 제한 차단

* **대응 핵심 기능**: IP 기반 `Rate Limit` (분당 3회, 일 20회) 어뷰징 방지

* **보이는 것**:

  * 안내 타이틀: *"잠시 쉬어가요! 발권 횟수를 초과했어요"*

  * 안내 문구: *"원활한 무료 서비스 운영을 위해 1분당 3회, 하루 최대 20회까지 추천받을 수 있어요. 잠시 후 다시 시도해 주세요."*

  * `처음으로 돌아가기` 버튼

* **누를 수 있는 것 / 누르면 생기는 일**:

  * **처음으로 돌아가기 버튼** → `S1` 이동

* **비어 있을 때**:

  * 해당 없음 (IP `Rate Limit` 초과 응답 발생 시에만 진입)

### S4. 서비스 일시 중단 (무료티어 소진)

* **대응 핵심 기능**: 무료티어 AI API 쿼터 소진 시 서비스 중단 제어

* **보이는 것**:

  * 안내 타이틀: *"오늘의 무료 발권이 모두 마감되었어요 ✈️"*

  * 안내 문구: *"「성격따라 따라가는 여행」은 무료티어 AI로 운영되고 있어요. 준비된 무료 할당량이 모두 소진되어, 할당량이 다시 충전될 때까지 잠시 쉬어갑니다. 다음에 다시 찾아와 주세요!"*

  * *(선택)* 서비스 상태 배지: `무료티어 충전 대기 중`

* **누를 수 있는 것 / 누르면 생기는 일**:

  * 무료티어 충전 전까지 서비스 중단 정책에 따라 별도 제출/재시도 액션 버튼 미제공.

* **비어 있을 때**:

  * 해당 없음 (서버에서 무료티어 쿼터 소진 상태 감지 또는 API 할당량 초과 응답 시 진입)

## 4. 확정 및 UX 권고 반영 사항 정리

| 항목 | 결정 내용 | 
| ----- | ----- | 
| **서비스명** | **「성격따라 따라가는 여행」** (S1 헤더, 로딩 문구, S2 보딩패스 브랜딩, S4 안내 문구에 반영) | 
| **무료티어 고지 (Q1)** | S1 하단에 무료티어 운영 및 한도 소진 시 중단 가능성, 데이터 미저장 고지 문구 배치 | 
| **무료티어 소진 처리 (Q2)** | 할당량 소진 시 `S4(서비스 일시 중단)` 화면 노출, 충전 전까지 신규 발권 중단 | 
| **미입력 제출 처리** | 필수 항목 모두 선택 전까지 제출 버튼 비활성화 + 안내 문구 표시 | 
| **AI 생성 로딩 상태** | 별도 화면 대신 S1 위 로딩 오버레이(스피너 + 항공사 컨셉 문구)로 대기 체감 시간 단축 | 
| **결과 카드 표기 범위** | AI 생성 텍스트 4종(`country`, `meme_title`, `meme_reason`, `tags`) + 유저 선택 조건 요약(MBTI·예산·기간·동행자·치안 중요도)을 보딩패스에 함께 표기해 공유 재미 강화 | 
| **결과 화면 재시도 / 빈 상태** | `다시 추천받기` 버튼 제공 / 새로고침·직접 진입 시 S1 자동 리다이렉트 | 
| **저장 피드백 / 인앱 대응** | 저장 완료 토스트 노출 + 카톡·인스타 인앱 브라우저 다운로드 제한 대비 외부 브라우저 안내 문구 추가 | 
| **연구 데이터 동의 UI** | 1차 MVP는 DB 미연동(`Stateless`)이므로 초기 이탈 방지를 위해 동의 체크박스는 2차 DB 연동 시점에 추가 |
